# 🎓 Student Grade Tracker

A Java Maven-based console application developed as part of the **CodeAlpha Java Programming Internship**.

## ✨ Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Calculate Grade
- Calculate Percentage
- Generate Report
- Store Data Using File Handling
- Input Validation

## 🛠️ Technologies Used

- Java 17
- Maven
- Object-Oriented Programming (OOP)
- File Handling
- VS Code

## 📂 Project Structure

```
src
 └── main
     └── java
         └── com.codealpha.studenttracker
             ├── model
             ├── service
             ├── util
             └── Main.java
```

## ▶️ How to Run

1. Clone the repository.
2. Open in VS Code.
3. Build using Maven.
4. Run `Main.java`.
